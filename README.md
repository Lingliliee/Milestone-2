# MMGMT 721 Milestone 2 – USD/CAD and Canadian energy exports to the U.S.

Data wrangling for the group project: how monthly changes in the USD/CAD exchange rate relate to the CAD value of Canadian energy exports to the United States, January 2018 – December 2025.

## Repository structure

```
├── data/
│   ├── raw/      original downloads (never edited)
│   └── clean/    clean tables written by Part 2 of the notebook
├── notebooks/
│   └── milestone2_pipeline.ipynb   shared notebook, one part per group member
├── docs/
│   └── cleaning_log.md             cleaning log generated by Part 2
├── .env.example     template for your own MotherDuck token (copy to .env, never commit .env)
├── pyproject.toml / uv.lock        environment for uv users
├── requirements.txt                environment for pip users
└── setup.bat                       one-click setup on Windows (uv)
```

## How to run

1. Set up the environment: double-click `setup.bat` (uv), or run `pip install -r requirements.txt`.
2. Open `notebooks/milestone2_pipeline.ipynb` in VS Code or Jupyter, select the project's Python environment as the kernel, and click **Run All**.
3. Only needed for MotherDuck: copy `.env.example` to `.env` and paste your own token.

## Working together on the notebook

- One person edits the notebook at a time: **pull** first, make your changes, **commit and push**, then tell the group.
- Add your code under your own part's heading; do not change other parts without asking the owner.

## Data sources

| Data | Source | Access |
|---|---|---|
| Monthly energy exports to the U.S. (Energy products [C12] and 7 sub-groups; Trade = Export; country of origin = Canada) | Statistics Canada, Table 12-10-0182-01, https://doi.org/10.25318/1210018201-eng | CSV "Download selected data (for database loading)" |
| Daily USD/CAD exchange rate (series FXUSDCAD, CAD per 1 USD) | Bank of Canada, https://www.bankofcanada.ca/rates/exchange/daily-exchange-rates/ | CSV through the Bank of Canada Valet API |
